# Contributions are closed

This repository is published as a read-only reference implementation. The upstream project does not accept commits, issues, feature requests, or pull requests from external users.

You may fork and adapt the project for a permitted noncommercial purpose under [LICENSE.md](LICENSE.md). Keep the required notices, replace reserved Pizza Warriors branding, and maintain your changes in your own fork.

Do not submit secrets, Discord webhooks, tokens, deployment URLs, workbook identifiers, combat logs, or SavedVariables data anywhere on GitHub.

Security vulnerabilities are the only exception to the no-contact policy. Report those privately as described in [SECURITY.md](SECURITY.md).
