# WotLK 3.3.5a compatibility audit

`PizzaRaidPlanner.toc` declares `## Interface: 30300`. The core addon uses the legacy APIs/events `GetNumRaidMembers`, `GetRaidRosterInfo`, `GetInstanceInfo`, `GetRealZoneText`, `UnitGUID`, `UnitIsConnected`, `RAID_ROSTER_UPDATE`, `PARTY_MEMBERS_CHANGED`, `ZONE_CHANGED_NEW_AREA`, `UNIT_PET`, `COMBAT_LOG_EVENT_UNFILTERED`, `PLAYER_REGEN_DISABLED`, and `PLAYER_REGEN_ENABLED`.

Combat-log data is received directly as event arguments. The addon does **not** call `CombatLogGetCurrentEventInfo`. UI construction uses `CreateFrame`, `UIPanelButtonTemplate`, `UIPanelCloseButton`, direct legacy `SetBackdrop`, `UIPanelScrollFrameTemplate`, and a normal multiline `EditBox`. When locally installed ElvUI 6.09 is available, guarded calls use its injected `SetTemplate` method, media values, and Skins handlers. The same window has a legacy fallback when ElvUI is absent. It does not use `BackdropTemplate`, Retail ScrollBox, modern Settings, `C_Timer`, `C_ChatInfo`, `C_AddOns`, `Enum`, `table.unpack`, Retail specialization APIs, or Retail encounter APIs.

The optional Skada adapter was checked against the locally installed Skada 1.8.87 (2024-03-23). All calls are guarded. It uses that build's `Skada:GetSet`, bound set/actor prototypes, `GetUnitSpec`, `GetUnitRole`, `GetDamageTargets`, and `GetDamageOnTarget`. Numeric Wrath spec IDs resolve unambiguous roles before Skada's role result; Skada's role remains authoritative for Death Knights because every DK tree could tank in 3.3.5. If Skada or a method is absent, PizzaRaidPlanner continues with its internal tracker. Talent lookup uses `LibGroupTalents-1.0` only when already available through `LibStub`; it is not bundled or required. A guarded read of `SkadaCharDB` is used only to recover the roster of a Festergut segment recorded before native history existed; every new history entry stores its own roster. Both BPC and BQL ranking use only the selected Festergut snapshot; the multi-boss average is never substituted.

ICC gating compares the localized instance or real-zone name returned by the legacy client with `Icecrown Citadel` and requires raid instance type when supplied. This matches the user's English Warmane client. NPC IDs are preferred for boss classification, with English encounter names as a private-server fallback.

No network APIs, workbook connector, secure action buttons, casts, target selection, or protected gameplay actions exist in the addon. It only displays and persists text that the player can manually copy into a blank worksheet.

In-game verification remains required for private-server combat-log spell/aura variants and BQL NPC GUID representation. Configured IDs are NPC `37955`, Essence variants `70867/71473/71532/71533/70879/71525/71530/71531`, Frenzy variants `70877/71474/70923`, bite variants `70946/71475/71476/71477/71726`, Aura Mastery `31821`, and Divine Sacrifice `64205`.
